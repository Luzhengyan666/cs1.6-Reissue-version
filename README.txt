CS 1.6 Web · 更新说明（r90 / 2026-10-31）
======================================

本版重点：AI 系统上线（每队 4 个 bot，用你上传的 t.glb / ct.glb），
另有霰弹枪回退、Beretta 92、画质与闪白修复、C4 提示与下包滴滴声。

一、霰弹枪：删掉 M12，双方各一把 M3
--------------------------------------------------
  · 按你的决定回到 r88 的状态：T / CT 的霰弹枪页各有一把 M3 Super 90；
  · M12 全链路移除（config 条目、v_/w_ 模型引用、购买分类、AI 武器表），
    assets 里的 m12 模型和音效文件保留但不被引用，删除不影响任何逻辑。

二、画质变模糊 + T 出生点闪白（同一个根因）
--------------------------------------------------
  · r89 的动态分辨率会在帧时间临界点反复 setPixelRatio，画布随之重建：
    画面在 0.72~1.0 之间来回跳（模糊），重建的那一帧天然闪一下白；
  · r90 起彻底去掉降分辨率逻辑：内部渲染永远按 settings.quality 满像素跑，
    tickPerf() 只留统计给 ?tune 面板看，不再改任何分辨率；
  · 顺带把时间步上限从 0.05s 放到 0.1s：低帧率时不再出现「走起来像拖地」。

三、新枪：Beretta 92（仅 CT / 手枪）
--------------------------------------------------
  · id `beretta92`，名字 Beretta 92，手枪类别，只有 CT 能买；
  · 15 发弹匣 / 备弹 60 / 伤害 25 / $650，射速与 USP 同档；
  · 模型 v_beretta92 / w_beretta92，第一人称机位暂借 glock18 的一套数值
    （同为单手机位），后续你在 ?tune 里调完可以直接写进 view-tune.js。

四、AI 系统（本版重点）
--------------------------------------------------
  4.1 角色模型
  · 用你上传的 t.glb（T）和 ct.glb（CT），每队 4 个 bot，共 8 个；
  · 模型是 CS 1.6 的 Z-up、英寸单位，浏览器里必须做数据级烘焙，不能靠
    Group.scale/rotate —— SkinnedMesh 的骨骼矩阵会二次变换，人直接缩成 4cm：
      - 顶点 ×k、骨骼静止 position ×k、动画 position 轨道 ×k、
        inverseBindMatrices 平移列 ×k，k = 1.78 / 模型真实身高；
      - 根节点 matrix 的平移一起缩，并把脚底钉到 y = 0；
      - 根骨骼 Bip01 的 translation 轨道是瑕疵数据（存的是另一套坐标，
        idle1 里 z = -1.68 而骨骼静止 z = 38.19），整条通道删掉，
        否则播 idle1 整个人会掉到地下 0.93m。
  · 80 个动作全部注册（idle1/walk/run/crouch*/jump/death*/ref_shoot_*/
    ref_reload_*/crouch_shoot_*/ref_aim_* …）。

  4.2 上下半身分层混合（复刻 GoldSrc）
  · 这套模型的动作是拆开的两套：idle1/walk/run/crouchrun 只有腿和根骨骼，
    ref_shoot_*/ref_reload_* 只有上半身（脊椎/双臂/头），彼此都没有对方的轨道；
  · 原版引擎是「下半身取移动动作 + 上半身取握枪动作」，r90 按同样规则在加载
    后把两条剪辑合成一条（腿取移动、上半身取握枪），否则移动时手臂会僵成 T-pose、
    开枪时腿不会动；
  · 合成结果按「握枪动作 + 移动动作」缓存，8 个 bot 共用，不重复占内存。

  4.3 手上的枪
  · 世界枪模型（w_*.glb）由 loadWorldGun() 归一化：蒙皮烘成静态网格、
    按武器类型缩放到真实米数（手枪 0.25 / 冲锋枪 0.55 / 步枪 0.85 /
    霰弹 0.92 / 狙击 1.05 / 机枪 0.95）、包围盒中心移到原点；
  · 每把枪绕 Y 的原始偏角都不一样，用一张 W_YAW 表统一转正，
    保证「枪管 = 模型 +X、枪身高度 = +Z」；
  · 挂载：右手骨骼上挂一个 holder，枪的握把点对到手掌；朝向每帧按角色朝向来算，
    换弹/下包时锁成「跟着手动」，枪会跟着换弹动作一起动；
  · **双臂 IK**：ref_shoot_* 这套动作本身摆不出持枪（双手是举起来的），
    所以自己解两段式 IK —— 右手压到胸前握把位置、左手压到护木位置
    （护木前移量按枪种给：步枪 0.30 / 冲锋枪 0.22 / 霰弹 0.34 / 手枪 0.07），
    蹲下时以胸骨为基准自动降高度；
  · 模型朝向：这套模型是朝局部 -X 的（背包在 +X 侧），MODEL_YAW 定成 90°，
    之前 180° 会让 bot 侧着身子跑。

  4.4 行为（对齐原版）
  · 巡逻 / 占点：0.9m 网格导航 + 最低面高度场（屋顶、拱门下面不会被判成孤岛）
    + A* 拉直；卡住 2 秒自动换一个附近目标绕路；
  · 交战：视野 + 射线遮挡判定，反应时间按 skill 随机 0.22~0.67s，
    点射（3~5 发一组，间隔按枪的射速），距离越远越散、蹲下更准、移动更散；
  · 蹲下 / 跳：交战时按距离和残血自行蹲下，跳只是越障动作；
  · 扔手雷：冷却 8~20s，会算落点、会喊 “Fire in the hole”；
  · 下包（仅 T）：带包的人走到包点 → 蹲下 → 播 ref_shoot_c4 → 3 秒后 C4 装上；
  · 拆包（仅 CT）：听到/看到包点后前往，蹲下拆 5 秒；
  · 死亡：随机 death1/2/3，8~12 秒后重生；命中会播对应的 flinch 动作。

  4.5 音效
  · 和玩家同一套采样：开枪、换弹（按动作时长分段）、脚步、手雷、下包滴滴；
  · playAt(name, pos, { ref, maxDist, panK })：按距离衰减 + StereoPanner 左右定位，
    listener 每帧跟相机，远处的枪声明显更闷更小；
  · 换弹/开火/脚步都做了节流，8 个 bot 同屏不会糊成一片。

--------------------------------------------------
  原因：包点黄圈是「贴地」画的，每次重建都要沿圆周逐点采样地面高度。

       每个三角形只算一次，整张图几毫秒烘完（取代上千条射线）；
    2. 顶点数固定，几何体只建一次，拖动时只原地改写 position 属性。
